# Touch 1 — Day 0 — the hook

Under 80 words. One CTA. No link.

```
{recent_event_about_them, one sentence, specific enough that it could not be
about any other company}

I'm {sender.first_name}, {sender.credibility_marker}, now building
{product.name}. We're a {credential_phrase} {product.category} with
{specific_capability}, so {their_users} could {outcome} without you building
{the_thing_they_would_otherwise_build}. {headline_offer}.

Worth a 15-min call?

{sender.first_name}
```

The first line's only job is to prove a person looked at this company. The
problem goes in sentence two, where it is framed by something they already know
is true about themselves.
