# Touch 4 — Day 17 — the diagnostic question

One question a practitioner would ask a peer. Answerable in one line.

```
{first_name},

Curious - is {company} handling {specific thing} in-house or through someone
else?

Asking because {one sentence on the pattern you have seen in comparable
companies, specific enough to be worth reading}.

{sender.first_name}
```

If you would not find the answer interesting regardless of whether it leads
anywhere, it is not a diagnostic, it is a pretext, and it reads like one.
