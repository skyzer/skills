# Templates

Five files, one per touch. They are scaffolds, not fill-in-the-blank forms: the
agent writes the actual copy against `skill/references/copy-rules.md` and uses
these for structure, length and intent.

- `touch-1-hook.md`  Day 0
- `touch-2-proof.md` Day 3
- `touch-3-value.md` Day 10
- `touch-4-diagnostic.md` Day 17
- `touch-5-breakup.md` Day 28

Placeholders in `{braces}` are filled from the brief (`config/brief.md`) and research.
